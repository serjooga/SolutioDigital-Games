# SolutioDigital Games — APK releases

Публичные APK игр студии [SolutioDigital](https://solutiodigital.net).

Файлы распространяются через [GitHub Releases](https://github.com/serjooga/SolutioDigital-Games/releases), не через Git-историю (бинарники слишком большие).

## Скачивание

Базовый URL релиза `v1.0.0`:

```
https://github.com/serjooga/SolutioDigital-Games/releases/download/v1.0.0/<filename>.apk
```

Список файлов — в [manifest.json](./manifest.json).
